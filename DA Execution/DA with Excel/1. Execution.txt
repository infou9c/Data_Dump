Basic Formulas
- Show data from {Basic Formulas}
	- Table 1
		=> =sum(range) OR => Alt=
	- Table 2
		=> =AVERAGE(range) OR => Alt HUA
	- Table 3
		=> =Max(range) OR => Alt HUM
	- Table 4
		=> =Min(range) OR => Alt HUI
	- Table 5
		- count - used to count only numbers
		=> =COUNT(range)
	- Table 6
		- countA - used to count all numbers, text
		=> =countA(range)
		=> =COUNTA(range) - count(range) gives count of numbers.
	- Table 7
		- countblank - used to count how many blanks
		=> =COUNTBLANK(range)

Advanced Formulas
- Show data from {Advanced Formulas}
	- Table 1
		- Upper, lower, proper
		=> =UPPER(B2)
		=> =LOWER(B2)
		=> =PROPER(B2)
	- Table 2
		- Left, Mid, Right
		=> =LEFT(B17,3)
		=> =MID(B17,4, 4)
		=> =RIGHT(B17, 3)
	- Table 3
		- Convert date in to desired format
		=> =TEXT(B32, "DD-MMM-yyyy")
		=> =TEXT(B32, "DDDD")
		> =TEXT(B32, "MMMM")
		> =TEXT(B32, "YYYY")
		=> =TEXT(B32, "DDD, DD-MMM-yyyy")
	- Table 4
		- Find due date
		=> =EDATE(B48, C48)
		=> =TEXT(D48, "DDD, DD-MMM-YYYY")
	- Table 5
		- Find total days between dates
		=> =DAYS(C65,B65) EndDate, StartDate
		- Find working days between dates. Sat-Sun off days
		=> =NETWORKDAYS(B65,C65) StartDate, EndDate
	- Table 6
		- If
		=> =IF(H88 <=35%, "Fail", "Pass")
	- Table 7
		- Find total of all values from a range for a criteria
			- SUMIF(RANGE, CRITERIA, SUM_RANGE)
			=> =SUMIF(B117:$B$616, $G$117, $C$117:$C$616)
				- After selecting range, click F4 to fix the range
				- After selecting criteria, click F4 to fix the range
				- After selecting sum_range, click F4 to fix the range
		- Find average of all values from a range for a criteria
			- AVERAGEIF(RANGE, CRITERIA, SUM_RANGE)
			=> =AVERAGEIF(B117:$B$616, $G$117, $C$117:$C$616)
		- Find count of all values from a range for a criteria
			- COUNTIF(RANGE, CRITERIA)
			=> =COUNTIF(B117:$B$616, $G$117)

- Lookup Formulas
- Show data from {Lookup Formula}
	- Table 1
		=> =VLOOKUP(G2, $B$2:$E$21, 4, FALSE)
		- Criteria, complete range, index of value column, False = exact match
	- Table 2
		=> =XLOOKUP(G12, $B$2:$B$21, $E$2:$E$21)
		- Criteria, column range of criteria, column range of values
