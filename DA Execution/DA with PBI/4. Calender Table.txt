- Create new project
- Blank report

- Modelling => Table option (Write a DAX expression to create a new table)

- DAX : Add date range
CalenderTable = CALENDAR(DATE(2024,1,1),TODAY())
	 
IMPORTANT: 
- Table Tools → Select Date Column → Mark as Date Table
- Mark as date table => On
- Choose a date column
- Sudmit
 
- DAX : Create formatted date column
FormattedDate = FORMAT(CalenderTable[Date], "dd-MMM-yyyy") 

- DAX : Extract Day
Day = DAY(CalenderTable[Date])

- DAX : Extract Month number
Month = MONTH(CalenderTable[Date])

- DAX : Extract Month name
MonthFullName = FORMAT(CalenderTable[Date], "MMMM")
MonthShortName = FORMAT(CalenderTable[Date], "MMM")

- DAX : Extract Year number
Year = YEAR(CalenderTable[Date])
YearShort = FORMAT(CalenderTable[Date], "YY")

- DAX : Extract Month Year name
MonthYearShort = FORMAT(CalenderTable[Date],"MMM yyyy")

- DAX : Extract Quarter number
Quarter = "Q" & QUARTER(CalenderTable[Date])

- DAX : Extract Quarter + Year 
QuarterYear = "Q" & QUARTER(CalenderTable[Date]) & "-" & FORMAT(CalenderTable[Date],"yyyy")

- DAX : Extract Week Day name
WeekDay = FORMAT(CalenderTable[Date], "dddd")
WeekDayShort = FORMAT(CalenderTable[Date], "ddd")

- DAX : Extract Week Day number
WeekDayNumber = WEEKDAY(CalenderTable[Date], 2)

- DAX : Extract IsWeekend
DayType =
IF(
    WEEKDAY(CalenderTable[Date],2) > 5,
    "Weekend",
    "Weekday"
)

- DAX : Extract FullDate in text formatted (Tuesday, September 1, 2026)
FullDate = FORMAT(CalenderTable[Date], "dddd") & ", " &  FORMAT(CalenderTable[Date], "MMMM") & ", " & FORMAT(CalenderTable[Date], "dd")& ", " & FORMAT(CalenderTable[Date], "YYYY")

FullDateShort = FORMAT(CalenderTable[Date], "ddd") & ", " &  FORMAT(CalenderTable[Date], "MMM") & ", " & FORMAT(CalenderTable[Date], "dd")& ", " & FORMAT(CalenderTable[Date], "YY")
